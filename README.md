# FH6 Walk

Приложение для iPhone: через ARKit определяет, где телефон в комнате и куда он смотрит,
и отправляет это по Wi-Fi программе на ПК. Программа превращает ходьбу с телефоном
в управление игрой: идёте — персонаж идёт, поворачиваете телефон — поворачивается взгляд.

## Сборка

Mac не нужен: неподписанный IPA собирает GitHub Actions (`.github/workflows/ios.yml`)
при каждом пуше в `main`. Проект Xcode генерируется из `project.yml` через XcodeGen.

## Установка на iPhone

1. Скачать `FH6Walk.ipa` из артефактов последней сборки (Actions → ios).
2. Подключить iPhone к ПК кабелем, открыть Sideloadly, перетащить IPA, войти своим Apple ID.
3. На iPhone: Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.
4. При первом запуске разрешить камеру и доступ к локальной сети.

С бесплатным Apple ID подпись живёт 7 дней, потом приложение нужно переустановить.

## Формат данных

UDP на порт 5701 ПК, 60 пакетов в секунду, 56 байт, little-endian: `FH6W`, версия (uint32),
PIN (uint32), номер пакета (uint32), время в секундах (float64), x, y, z в метрах (float32,
ARKit: y вверх), кватернион x, y, z, w (float32), качество отслеживания (uint8), 3 нулевых
байта. Описание в коде: `FH6Walk/PosePacket.swift`.
